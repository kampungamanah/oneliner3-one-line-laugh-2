# oneliner3-one-line-laugh-2

This repository holds a single joke submitted to [make.fun's "One Line, One Laugh" bounty](https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3), a $2 USDC prize pool judged head-to-head by an AI comedy editor. [Join make.fun](https://make.fun/r/1gbngh2r).

The gag opens in a therapist's office and ends in a lawyer's office: the same sentence about humour as a defence mechanism turns out to describe an alibi as well, and that second meaning is the whole punchline. Nothing is explained twice and nothing is padded — the setup hands the reader one innocent reading, then the ending swaps it for a much guiltier one.

## The line

Running `main.ts` writes `/output/entry.txt` containing exactly the following, with no newline at the end:

> My therapist says I use humour as a defence mechanism, which is hilarious because my lawyer says the same thing about my alibi.

## Running it

    node main.ts

If `$MAKEFUN_OUTPUT_DIR` is set, the entry is written there; otherwise it goes to `/output`.
